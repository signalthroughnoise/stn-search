# STN Search Suite

Signal Through Noise search tools in one page:

- **Cue Sheet** — music search across Extreme Music, APM, Audiomachine, Getty Images Music, Megatrax and Spotify
- **Second Unit** — stock footage search across Shutterstock, Getty, iStock, Storyblocks, Pond5, Artgrid, Filmsupply and Frameset
- **Take One** — template search across Envato Elements and Motion Array

Everything is a deep link into each platform's own search. No API keys, no backend, nothing scraped.

## Using it

- Open the site in Chrome. To install it as its own app, use the install icon in the address bar.
- Jump straight to a tool with `#music`, `#stock` or `#templates` at the end of the URL.
- Inside the Premiere Pro panel (CEP), links open in your default browser automatically.

## Files

- `index.html` — the whole app (logo embedded)
- `manifest.webmanifest`, `sw.js`, `icons/` — make it installable and usable offline
